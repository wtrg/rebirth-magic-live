# Original runtime assets

The ten actor/pet templates share one self-contained [GLB bundle](../public/models/raid.glb), generated from [models.ts](../apps/game/models.ts). Arena geometry is generated by [scene.ts](../apps/game/scene.ts). Character, boss, pet and world sources therefore remain in these two owned factories rather than duplicated asset folders.

[manifest.json](manifest.json) is measured from the committed binary by `node scripts/inspect-models.ts`. Run it after `node scripts/export-models.ts` and commit both the bundle and updated manifest when models change. Repeated inspection of the same binary produces identical output. No network media is loaded by the inspector.

The [art specification](../docs/ART_SPECIFICATION.md) documents size, proportions, colors, articulation, camera, lighting and future replacement requirements. All current geometry is original, Codex-authored and MIT-licensed. Gemini delivery and Leader approval remain pending.
